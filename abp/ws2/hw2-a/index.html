What is Claude Code?

Claude Code is a major innovation from Anthropic (OpenAI followed up with a clone called Codex; an open source alternative is called OpenCode). The idea is simple (which makes it even better).

  1. Instead of copy/pasting code back and forth from Chat interfaces (like ChatGPT or Claude), Claude Code is a tool that simply writes directly onto your computer.
  2. Instead of using complicated editors and heavy software, the tool is made to live directly in the terminal. This allowed Anthropic to quickly develop a robust tool, and to focus on the main ideas.
  3. Instead of editing code or documents yourself, you describe to the AI what you want to be changed. By design, you use it as an agent.

Better safe than sorry

Even though Claude Code usually has good intentions, it might accidentally do things on your computer that have seriously bad consequences. Hence, it’s always asking you for permission before doing something. Quickly, people said yes to everything instead of reading the fine print. Hence, developers decided to build sandboxes: within the sandbox, the AI can do what it wants, it might also reach out on well-defined paths, but that’s it.

We use the sandbox tool called nono. We configure it so that Claude Code can

  • only write in one folder: ~/kingo-pod/claude,
  • read the rest of kingo-pod to understand how it works,
  • reach out to n8n and Langflow,
  • access the internet, and
  • not do anything else on your laptop.

Typically, Claude Code uses the Claude models from Anthropic. Here, we use it with the model GLM 5.3 Flash, paid with the OpenRouter key you already have.

1. Update kingo-pod: get the new command kingo claude

Open a terminal and run this one line:

cd ~/kingo-pod && ./kingo update

When it is done, run

./kingo help

You should see a line that starts with kingo claude.

Stuck? Help for step 1

2. Install Claude Code and its sandbox

One line installs three programs: nono (the sandbox), psql (so that Claude can talk to your database) and Claude Code. Run the line for your laptop, in the same terminal.

On a Mac:

brew install nono libpq && curl -fsSL https://claude.ai/install.sh | bash

On WSL (Ubuntu in Windows):

curl -fsSL https://nono.sh/install.sh | sh && sudo apt install -y postgresql-client && curl -fsSL https://claude.ai/install.sh | bash
Already using Claude Code?

Run the line anyway: it installs Claude Code the way Anthropic recommends, or brings it up to date. Your own settings and your login stay as they are.

You installed it with Homebrew or npm instead? Then you now have it twice. ./kingo claude always takes the new one. To keep only the new one, remove the old one:

  • Homebrew: brew uninstall --cask claude-code
  • npm: npm uninstall -g @anthropic-ai/claude-code

Stuck? Help for step 2

3. Give Claude permission to work in n8n

Claude reads and changes your workflows through n8n’s API. Claude needs an API key issued by n8n to do that.

  1. Open n8n at http://localhost:5678 and sign in.
  2. Click Settings at the bottom of the left sidebar, then n8n API.
  3. Click Create API key. In the window Create API Key:
    • Label: claude
    • Expiration: Never. Then the key works for the whole course.
  4. Click Save. Copy the key and keep it for step 4: n8n shows it only once.

Stuck? Help for step 3

4. Start Claude Code and give it its keys

In the terminal, run:

cd ~/kingo-pod && ./kingo claude

Always start Claude Code for the course this way. A plain claude starts a standard Claude Code, without the sandbox and without the course settings (what is different).

The first time, kingo claude asks for two keys. You do not see a key as you paste it: that is on purpose.

  1. Paste your OpenRouter key (or your group’s key) and press Enter.
  2. Paste the n8n key from step 3, and press Enter.
Don’t I need to give it a key to Langflow?

kingo-pod can make this and hand it to Claude. To be honest, if you have superuser access to the database used by Langflow (and by n8n), and to the file system, then you can get a lot of credentials. Feel free to ask Claude Code more about this later. And while you’re at it, you can ask how an admin can extract credentials saved to n8n.

Then Claude Code starts and asks a few questions of its own:

  1. Pick a theme for Claude Code that you like, and press Enter.
  2. Do you trust the files in this folder? Choose Yes.

You see Claude Code waiting for your first words. Well done: your coding agent is set up.

Stuck? Help for step 4

5. Let’s try it out

Type this and press Enter:

List my n8n workflows and tell me in one sentence each what they do.

Before Claude runs a command, it asks you. Read what it wants to do, then agree. You should see WS2.0, WS2.1, WS2.3 and WS2.4, each with a sentence. That is Claude reading your n8n.

To leave Claude Code (and to get back to the terminal), run

/exit

Sometimes when exiting Claude code, you get a question from nono sandbox, if it should give Claude code further permissions. Only add something if you know what you’re doing.

Now you can continue using this terminal as usual (you can also just open another one like you can open another tab in your browser).

Stuck? Help for step 5

6. See the instructions Claude reads at every start

Claude reads the file AGENTS.md in its folder at every start (actually, it reads CLAUDE.md which here just has a link to AGENTS.md). You can have a look inside (the cat command just prints the content of the file into the terminal and you can continue using the terminal as usual):

cat ~/kingo-pod/claude/CLAUDE.md

And

cat ~/kingo-pod/claude/AGENTS.md

With your team’s rules in AGENTS.md, Claude builds the way your team decides: the same names, the same contracts between flows and between tools.

Start Claude again with

cd ~/kingo-pod && ./kingo claude

and ask:

What are our team's rules?

Claude should say that your team has not added its rules yet. That is right, and it shows that Claude has read AGENTS.md.

How do I change AGENTS.md myself?

With nano, an editor inside the terminal. It works the same on a Mac and in the Ubuntu app:

nano -w ~/kingo-pod/claude/AGENTS.md

(-w keeps long lines as they are.)

  • Move with the arrow keys, and type as usual. A mouse click does not move the cursor.
  • Paste: on a Mac Cmd+V, in the Ubuntu app a right click.
  • Save: Ctrl+O (on a Mac the key control, not command), then Enter.
  • Leave nano: Ctrl+X.

The two lines at the bottom of nano show these keys: ^O means Ctrl+O.

Claude reads AGENTS.md only when it starts. After a change, leave Claude with /exit and start it again.

Try it: add this line at the very end of AGENTS.md, with your own language if it is not Korean:

Always answer me in Korean.

Save, /exit and start Claude again with

./kingo claude

and ask it something: it answers in Korean. Keep the line, or delete it again.

It’s a good idea to add your team’s design rules to AGENTS.md.

Stuck? Help for step 6

What Claude can do, and what it cannot

Careful, if you just type claude, then Claude code runs in the standard way as anthropic had it set up. Please always use

./kingo claude

This way, it’s in the nono sandbox.

Claude canClaude cannot
read and write in ~/kingo-pod/claudewrite anywhere else on your laptop
read kingo-pod: compose.yml, the guideschange kingo-pod, or run ./kingo
change your n8n workflows, Langflow flows and databasesee your keys: it gets stand-ins
look things up on the websee your own Claude Code settings, if you use Claude Code already

Sometimes, Claude code wants to execute a command (which we don’t allow), and then it’ll tell you to run a command on its behalf in the terminal

ONLY RUN A COMMAND IN YOUR OWN TERMINAL IF YOU UNDERSTAND IT.

Claude cannot leave its sandbox, but a command you type does. When Claude says that the sandbox blocks it, that is the sandbox doing its job. When the sandbox asks you to give additional permissions after leaving Claude, then only add something if you know what you’re doing.

You decide: should Claude ask before every command?

So far Claude asks you before it runs a command or changes something. You can also let it work without asking. To this end, you start it with this line:

./kingo yolo

The first time, Claude Code asks whether you accept this mode. Choose Yes, I accept.

./kingo claude./kingo yoloclaude (without kingo)
Your laptop isprotected by the nono sandbox and by Claude Code’s hesitationsprotected by the nono sandboxprotected only by Claude Code’s hesitations: no sandbox
Your workflows, flows and databaseyou see every change before it happensClaude changes them at once, mistakes tooout of reach at first, as Claude has no keys for them; but it can read every file you can, your keys too
Your user experiencemany requests for permissions, often the same onesClaude works on by itselfAnthropic’s standard Claude Code: your own Anthropic login and bill, and the usual requests for permissions

Inside the sandbox, Claude Code’s requests for permission do not protect your laptop: the sandbox does that, with or without them. They protect your project from Claude’s mistakes. If you let Claude work without asking, save your work first. This line saves your n8n workflows and your Langflow flows into ~/kingo-pod/backups/ (not your own tables in the database):

cd ~/kingo-pod && ./kingo backup

Many people start with the requests for permission and switch once they trust what Claude does in their project. It is your choice, and you can change it at every start.

What is different from a standard Claude Code, and where it is configured

The Claude Code you started with ./kingo claude is set up for the course.

Important: the course setup holds only when you start Claude with ./kingo claude or ./kingo yolo. When you type claude anywhere, you get a standard Claude Code with Anthropic’s settings: no sandbox, your own ~/.claude, your own Anthropic login. Even in ~/kingo-pod/claude, a plain claude runs without the sandbox and without the keys.

In detail: what the course changes, and where

What is different from a Claude Code you install and start with claude, and the file where the course configures each part:

A standard Claude CodeHere, started with ./kingo claudeConfigured for the course in
Startclaude, in any folder./kingo claude in the kingo-pod folder; ./kingo yolo is the same without requests for permission. Claude works in kingo-pod/claudekingo-pod/kingo, the script behind every ./kingo command. Before Claude starts, it checks that n8n and Langflow run, asks for your keys the first time, copies AGENTS.md, CLAUDE.md and .claude/settings.json into kingo-pod/claude/ the first time, and writes the nono profile. Then it starts Claude Code inside nono.
Model and billClaude models, with an Anthropic account or keyGLM 5.3 Flash through OpenRouter, paid with your OpenRouter keykingo-pod/claude/.claude/settings.json names the model, for every role (ANTHROPIC_MODEL and the lines ANTHROPIC_DEFAULT_…_MODEL). The nono profile sends Claude’s requests to OpenRouter instead of Anthropic, and puts your OpenRouter key into them.
Keyskept by Claude Code itselfkept in ~/.config/kingo/; Claude sees only stand-inskingo-pod/kingo asks for your OpenRouter and n8n keys, makes the Langflow key itself, and keeps them in ~/.config/kingo/, readable only by you. When it starts Claude, it hands them to nono, not to Claude. The nono profile says, for OpenRouter, n8n and Langflow, where nono’s proxy puts the real key into a request.
FilesClaude reads and writes wherever you may, after askingClaude writes only in kingo-pod/claude and ~/.kingo-claude, reads kingo-pod, and nothing else; the operating system enforces itThe nono profile ~/.config/nono/profiles/kingo-claude.json lists the folders Claude may read and write, and the few environment variables that reach Claude: other keys on your laptop do not. kingo writes it anew at every start from kingo-pod/setup/claude/nono-profile.json, so a change to it does not last. On top, kingo-pod/claude/.claude/settings.json forbids Claude to read .env files, ~/.ssh and ~/.aws.
SandboxClaude Code’s own sandbox, for commands only, if you turn it onnono, around all of Claude Code: its commands, and its own tools for files toothe nono profile. kingo-pod/claude/.claude/settings.json turns Claude Code’s own sandbox off (sandbox.enabled): nono covers more.

An Anthropic login stored there, kingo removes at every start: the course does not use it, and Claude could read it.

Memoryhidden in ~/.claude/projects/in kingo-pod/claude/memory/, where you can read itkingo-pod/claude/.claude/settings.json (autoMemoryDirectory)

Requests for permissionClaude asks before a commandthe same; ./kingo yolo turns them offkingo-pod/kingo: ./kingo yolo starts Claude with --dangerously-skip-permissions. The sandbox stays the same.
UpdatesClaude Code updates itselfno self-update: run the install line againkingo-pod/claude/.claude/settings.json: CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC also turns off the self-update.

Claude’s memory. Claude Code writes down for itself what it learns about your project, so that it still knows it in the next session: for example a name your team chose, or a mistake it should not make again. Usually this memory is hidden in Claude’s own folder. Here it lies in ~/kingo-pod/claude/memory/, so you can read what Claude remembers, and correct or delete it. The file MEMORY.md there lists everything it keeps.

Claude can explain all of this itself. Ask it:

How are you set up here, and what is different from a standard Claude Code?

If something goes wrong

Find your step. Still stuck? Write to Frank: then we fix it together.

Step 1

What you seeWhat to do
./kingo help shows no kingo claudeRun ./kingo update again and look for errors near the end. Send Frank what ./kingo version shows.

Step 2

What you seeWhat to do
brew: command not found (Mac)The line needs Homebrew. It is missing, or your Terminal does not find it. Do Step 1 — Install Homebrew of the kingo-pod Mac guide, with its “Next steps” lines. Open a new Terminal window and run the line again.
Unable to locate package (Windows)Run sudo apt update, then the line again.
A download errorCheck that you are online, then run the line again.
The line says that a folder is not on your PATHNothing to do: ./kingo claude finds the programs anyway.

Step 3

What you seeWhat to do
You closed the window before you copied the keyMake a new key the same way. In the list on the page n8n API, delete the old one.

Step 4

What you seeWhat to do
nono is not installed or Claude Code is not installedRun the line of step 2 again.
n8n and Langflow must be running firstRun ./kingo up, then step 4 again.
n8n did not accept the keyMake a new key as in step 3. Then run ./kingo claude again: it asks for the key.
openrouter did not accept the keyCheck the key Yanbo gave you. Then run ./kingo claude again: it asks for the key.
Claude Code asks you to log in to AnthropicDo not log in. Type /exit and write to Frank.
removed an Anthropic loginYou logged in to Anthropic inside ./kingo claude. kingo removed that login again: the course does not use it, and Claude could read it there. Your own Claude Code login is not affected.

Step 5

What you seeWhat to do
Claude says it cannot reach n8nCheck that n8n opens at http://localhost:5678. If not, run ./kingo up in your own terminal, then ask again.

Step 6

What you seeWhat to do
No such file or directory./kingo claude makes these files at its first start. Do step 4 first.
