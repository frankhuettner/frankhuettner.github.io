Sometimes, Claude Code wants to execute a command (which we don’t allow), and then it’ll tell you to run a command on its behalf in the terminal.

Only run a command in your own terminal if you understand it. Claude Code cannot leave its sandbox, but a command you type does. When Claude Code says that the sandbox blocks it, that is the sandbox doing its job.

Quiz. In step 4 you gave kingo your n8n key. Does Claude Code know the key now?

  • Yes: it needs the key to reach n8n
  • No: it gets a stand-in
Show the answer

No. Claude Code gets only a stand-in. nono keeps the real key and puts it into each request that Claude Code sends to n8n. Hence, your key is not uploaded to the provider of the LLM, but Claude Code can still use it. The Langflow key and your OpenRouter key are kept the same way.

8. Claude Code always asks for permission: should we tell it to just do its job?

Claude Code always works in one of four modes. The mode decides who says yes before a command runs: you, the AI, or nobody. The line under your text shows the mode, for example ⏸ manual mode on.

The mode does not decide where Claude Code can write. The nono sandbox does that, as the table above shows: Claude Code cannot write into any other folder on your laptop, such as Documents or Desktop, with or without your permission. The mode only decides whether Claude Code asks you first.

To change the mode, press Shift+Tab. Each press takes you one mode further, in this order:

  1. ⏸︎ manual mode on: Claude Code asks you before it writes a file and before it runs a command. ./kingo claude always starts here.
  2. ⏵⏵ accept edits on: Claude Code writes files in its folder ~/kingo-pod/claude without asking. Before a command, it still asks you.
  3. ⏸︎ plan mode on: Claude Code changes nothing. It writes a plan and asks for your yes.
  4. ⏵⏵ auto mode on: the AI decides itself whether it needs to ask you for permission.

One more press of Shift+Tab, and you are back in manual mode.

Quiz. The line under your text says plan mode on. You ask Claude Code to rename a workflow. What happens?

  • Claude Code renames the workflow
  • Claude Code writes a plan and asks for your yes
Show the answer

Claude Code writes a plan and asks for your yes. In plan mode, it changes nothing before you agree to the plan.

⏵⏵ There is a fifth way, where nobody says yes or no: you start Claude Code with ./kingo yolo instead of ./kingo claude. Then Claude Code never asks for permission.

What does this mean for you? In this homework, Claude Code rarely writes files. It mostly runs commands to search, and to talk to n8n, Langflow and your Postgres database. In accept edits mode, Claude Code still asks you before each of these commands. The requests stop only in auto mode, or with ./kingo yolo.

Which mode should you use? Auto mode is okay. Claude Code runs inside the nono sandbox, so the sandbox protects your laptop in every mode. And every start of ./kingo claude saves your n8n workflows and your Langflow flows. In manual mode, you get many requests, and the commands are hard to read. So feel free to switch to auto mode: press Shift+Tab until the line under your text says auto mode on.

In manual mode, Claude Code asks before each command. Yes runs the command. No stops Claude Code: then tell it what to do instead, or type continue.

Quiz. You are in auto mode. Claude Code tells you that a request was blocked, and asks whether it may try again. It is the change you asked for. What do you do?

  • Type /exit and start again
  • Say yes, and name what it may do
  • Nothing: Claude Code finds another way
Show the answer

Say yes, and name what it may do, for example: Yes, retry saving the change to the copy. In auto mode, the AI may refuse a command that you asked for. Is it blocked again? Press Shift+Tab until the line under your text says manual mode on, and say it again.

9. You decide: ./kingo yolo starts Claude Code without any check

In each of the four modes, someone checks a command before it runs: you, or the AI. You can also start Claude Code with no check at all. To this end, you start it with this line:

./kingo yolo

The first time, Claude Code asks whether you accept this mode. Choose Yes, I accept.

./kingo claude ./kingo yolo claude (without kingo)
Your laptop isprotected by the nono sandbox and by Claude Code’s hesitationsprotected by the nono sandboxprotected only by Claude Code’s hesitations: no sandbox
Your workflows, flows and databaseyou see every change before it happensClaude Code changes them at once, mistakes tooout of reach at first, as Claude Code has no keys for them; but it can read every file you can, your keys too
Your user experiencemany requests for permissions, often the same onesClaude Code works on by itselfAnthropic’s standard Claude Code: your own Anthropic login and bill, and the usual requests for permissions

The requests for permission protect your project from Claude Code’s mistakes. If you let Claude Code work without asking, save your work first. This line saves your n8n workflows and your Langflow flows into ~/kingo-pod/backups/ (not your own tables in the database):

cd ~/kingo-pod && ./kingo backup

Quiz. Claude Code changed your n8n workflow WS2.3 - Triage New Mail, and now it does not work. Where is the version from before?

  • It is gone
  • In ~/kingo-pod/backups/flows/
  • In Claude Code's memory
Show the answer

In ~/kingo-pod/backups/flows/. Every start of ./kingo claude or ./kingo yolo saves each n8n workflow and each Langflow flow there as one JSON file, in a folder per start. The newest 10 starts stay. You can import such a file again in n8n or in Langflow.

10. What is different from a standard Claude Code, and where it is configured

The Claude Code you started with ./kingo claude is set up for the course.

Quiz. You are in the folder ~/kingo-pod/claude and type claude. Are you in the sandbox?

  • Yes: the folder belongs to kingo-pod
  • No
Show the answer

No. Then you get a standard Claude Code with Anthropic’s settings: no sandbox, your own ~/.claude, your own Anthropic login. Even in ~/kingo-pod/claude, a plain claude runs without the sandbox and without the keys. Here, you’re on your own, kid.

The course setup holds only when you start Claude Code with ./kingo claude or ./kingo yolo.

Claude Code’s memory. Claude Code writes down for itself what it learns about your project, so that it still knows it in the next session: for example a name your team chose, or a mistake it should not make again. Usually this memory is hidden in Claude Code’s own folder. Here it lies in ~/kingo-pod/claude/memory/, so you can read what Claude Code remembers, and correct or delete it. The file MEMORY.md there lists everything it keeps.

Claude Code can explain all of this itself. Ask it:
